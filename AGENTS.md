# ShiftNest — PA#2 Project Rules

## Stack
- Static HTML5 and CSS3.
- Mobile-first responsive design.
- No React, Vue, JavaScript framework or build step.
- No new dependencies without team approval.

## HTML
- Use semantic landmarks: header, nav, main, footer.
- Exactly one h1 per page; no skipped heading levels.
- All form inputs must have visible labels.
- All images must have alt attributes.
- Navigation must use relative .html links.
- No onclick-based page navigation.

## CSS
- Use a consistent spacing scale and CSS variables.
- Support 360px, 768px and 1280px.
- No horizontal page overflow or clipped content.
- Standalone buttons and links must be at least 44px tall.
- Body text must be at least 16px.
- Maintain text contrast of at least 4.5:1.
- Avoid !important and arbitrary spacing values.

## Constraints
- Implement only the three PA#1 main-flow screens.
- Pages must work with JavaScript disabled.
- Do not modify the original PA#1 artifacts.
- Do not fabricate test evidence or AI-LOG entries.

## Verification
- Test all three viewport widths.
- Validate every HTML page with W3C (0 errors).
- Check accessibility and navigation.
- Capture full-page screenshots with JavaScript disabled.
